# T-033: скилл «tiermaker» для агентов + сквозная проверка

## Цель
Скилл в репо `tiermaker-mcp`, который учит агента делать хорошие тир-листы через MCP: от запроса пользователя
до PNG и ссылки в редактор. Проверить сквозным прогоном реальным агентом на dev.

## Контекст
- Репо `<local-path> (коммит 39b3df6), README и `src/tools.ts`.
- План `.team/tasks/mcp-v1-plan.md` п.3.
- Формат скиллов Claude: `SKILL.md` с frontmatter `name`, `description` (когда срабатывать). Пример устройства — любой скилл в `~/.claude/skills/*/SKILL.md` (читать 1–2 для формы, не копировать содержание).

## Что сделать
1. `skills/tiermaker/SKILL.md` (EN, короткий, ≤ 120 строк) + при необходимости `skills/tiermaker/references/*.md`:
   - когда срабатывать: «сделай тир-лист / tier list / рейтинг по тирам …»;
   - шаги: уточнить тему только если она пустая → `search_templates` (есть подходящий — из шаблона) → тиры (по умолчанию S–D; свои, если просит: «must watch / skip» и т.п.) → 10–40 элементов → расстановка с кратким обоснованием → `get_tierlist` самопроверка → `render_image` → `get_editor_link`;
   - картинки: только прямые http(s) URL, если уверен в источнике; иначе текстовые элементы (не выдумывать URL);
   - ответ пользователю: PNG + ссылка + 1–3 строки «почему так», предложение поправить;
   - что делать при ошибках инструментов (лимиты, длинная ссылка → файл);
   - язык ответа = язык пользователя.
2. README: раздел «Skill» — как установить (Claude Code: скопировать в `~/.claude/skills/` или через plugin; другие агенты — как системный промпт).
3. Сквозной прогон на dev: подключить MCP к Claude Code в отдельной сессии/процессе (`claude -p` или аналог с `--mcp-config`, `TIERMAKER_BASE_URL=http://localhost:3000`) со скиллом, 3 запроса:
   «tier list of Marvel movies», «тир-лист языков программирования для новичка, тиры: учить / можно / не надо», «тир-лист из шаблона <любой существующий на dev>».
   Для каждого: ссылка открывается в dev-редакторе, тиры/элементы на месте, PNG создан. Транскрипт кратко (вызовы инструментов) в отчёт.
4. Найденные неудобства инструментов (ошибки, лишние вызовы) — исправить в MCP, если мелко; иначе список в отчёт.
5. `CHANGELOG.md` репо MCP.

## Не делать
- Не публиковать, не пушить, не трогать прод. Скилл не ставить глобально в `~/.claude/skills/` пользователя (только во временную папку для прогона).

## Критерии приёмки
- 3 сквозных прогона успешны; транскрипты и результат в отчёте `.team/tasks/T-033-tiermaker-skill.report.md` (сайтовый репо).
- lint/test/build MCP зелёные в Docker; grep на утечки инфраструктуры пуст.
- Коммиты в tiermaker-mcp.

## Проверки (тестер)
- Прочитать SKILL.md: нет выдуманных URL-инструкций, шаги соответствуют реальным инструментам.
- Повторить один сквозной прогон самостоятельно.
