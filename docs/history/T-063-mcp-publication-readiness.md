# T-063: Продолжить подготовку публикации MCP

## Цель
Завершить доступные без входа владельца проверки и подготовить точный статус публикации TierMaker.ru MCP.

## Контекст
- `../tiermaker-mcp/docs/publication-status.md`
- `.team/tasks/T-063-publication-recon.notes.md`
- Исходный план пользователя находится в сессии codex3 `01a1c669-f70c-7f91-9eba-5f0f51d1ff9c`.

## Что сделать
- Проверить весь актуальный Git history MCP на секреты и личные данные перед публикацией; не выводить найденные секреты.
- Проверить готовность релизных материалов и заявок и выполнить независимые доступные проверки из плана.
- Если есть авторизованные клиентские сессии, выполнить реальные прогоны Claude и ChatGPT, не выдавая их за пройденные без доказательств.
- Зафиксировать результаты и конкретные блокировки в отчёте; при необходимости обновить документацию и changelog, закоммитить только свои изменения.

## Не делать
- Не публиковать, не создавать репозитории, не выполнять push, не менять production и настройки аккаунтов в рамках этой разведки.
- Не входить в аккаунты за пользователя, не собирать и не выводить секреты; не изменять реальные доски пользователей.

## Критерии приёмки
- Аудит охватывает текущий HEAD и всю историю, указаны метод и ограничения.
- Каждый клиентский прогон либо подтверждён, либо указана точная причина блокировки.
- Отчёт называет конкретные дальнейшие действия и результаты проверок.

## Проверки
- Read-only проверки и точечные проверки в dev-контейнере по необходимости; результаты перечислить в отчёте.
- Прод: только read-only наблюдение; запись и публикация запрещены.
