# T-030: разведка — что нужно для MCP-сервера, создающего тир-листы без аккаунта

## Цель
Пользователь хочет OSS MCP-сервер + скилл: агент без авторизации (как гость сайта) создаёт тир-листы и гибко
настраивает структуру (тиры, названия, цвета, порядок) и содержимое (элементы: текст, картинки по URL, расстановка).
Нужна фактура по текущему API, чтобы architect спланировал v1. Только чтение кода, без изменений.

## Контекст
- `backend/api/tier_lists/views.py`, `backend/api/serializers.py`, `backend/api/urls.py`, `backend/api/throttles.py`,
  `backend/api/access.py`, `backend/api/middleware.py`, `backend/api/template_public_views.py`, `backend/api/storage_utils.py`.
- Фронт: `frontend/lib/proxy-anonymous-identity.ts`, `frontend/lib/save-feedback.ts`, `frontend/app/create/**`, `frontend/app/tierlist/**`, `frontend/app/api/**`.

## Ответить (каждый пункт — с путь:строка, кратко)
1. Гостевой путь сейчас: как гость создаёт/сохраняет доску (сервер или только браузер), чем идентифицируется (cookie/заголовок/anonymous id), как потом редактирует, есть ли «забрать в аккаунт». Идёт ли это через Next proxy (`frontend/app/api`) или напрямую в Django.
2. Эндпоинты, нужные MCP: поиск/список шаблонов и категорий, получение шаблона с элементами, создание доски (из шаблона и с нуля), изменение структуры и элементов, публикация/шаринг, получение ссылки. Для каждого: метод, путь, обязательные поля, доступность гостю.
3. Модель данных доски: как хранятся тиры (имя, цвет, порядок) и элементы (текст, картинка, позиция, «не распределено»); лимиты (кол-во тиров/элементов, длины, размер payload).
4. Картинки: можно ли гостю добавить элемент по URL картинки (серверная загрузка/безопасный fetch), или только upload файла; лимиты размера/типов; куда кладётся.
5. Защита гостевого пути: throttles (ставки, ключ — IP/X-Real-IP/anonymous id), captcha (есть ли, на каких действиях — критично для MCP), блокировки, подписанные проверки. Что сломает/заблокирует программного клиента.
6. Публичность: видна ли гостевая доска по ссылке, индексируется ли, модерация, может ли гость опубликовать в каталог.
7. Рендер картинки тир-листа: есть ли серверный экспорт PNG (`tier_lists/exports`?) и доступен ли гостю.
8. CORS/CSRF для внешнего клиента (MCP ходит из Node, не из браузера).
