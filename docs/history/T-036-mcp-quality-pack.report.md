Теперь запрашивается 500, а результат отбрасывается, если ширина в URL (`/NNNpx-`) или `thumbwidth` > 512 или это не thumbnail (оригинал). Тесты: 960px/широкий/оригинал не попадают в выдачу. Живая проверка (Toyota Camry, Bulbasaur, Eiffel Tower): все `500px`, 200 `image/jpeg`.

Тесты: slug + произвольные URL без поиска → fail; недоступный шаблон → fail; добавленный после шаблона URL требует поиска.
- **P2 ссылки:** считаются все вхождения, повтор той же ссылки = fail (тест обновлён).
- Docker lint/test (72)/build зелёные; `rg` запрещённых слов пуст.
