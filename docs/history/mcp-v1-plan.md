# План: tiermaker MCP + скилл, v1 без авторизации (2026-10-24)

Основа: разведка `.team/tasks/T-030-mcp-recon.notes.md`.

## Ключевой факт
Гость сайта не сохраняет доску на сервере: редактирует в браузере (черновик в localStorage), PNG — клиентский canvas,
save/share требуют входа. Значит «как гость» = MCP собирает доску у себя и отдаёт
(а) PNG и (б) ссылку, открывающую эту доску в редакторе tiermaker.ru как гостевой черновик. Сохранить/поделиться — пользователь сам, после входа.
Серверных гостевых досок, токенов и новых write-эндпоинтов в v1 нет → нет новой поверхности для спама.

## Состав
1. **Сайт (private репо): T-031 «импорт доски по ссылке»**
   - `/create#tm=<base64url(deflate(JSON))>` (фрагмент не уходит на сервер и не логируется). Редактор валидирует, ограничивает размер, кладёт как гостевой черновик, без автосохранения.
   - Публичная схема `TierListImport v1`: `version, title, templateSlug?, tiers[{id,label,color}], items[{id,label?,imageUrl?}], placements{tierId:[itemId]}`; не размещённые → пул.
   - Лимиты v1: ≤ 200 элементов, ≤ 20 тиров, ссылка ≤ ~30 КБ; внешние картинки — только http(s), показ через существующий `/api/image-proxy` (CSP `img-src` внешние хосты не пускает); при сохранении сервер скачивает их уже существующим безопасным путём.
   - Если ссылка слишком длинная — запасной путь: MCP сохраняет `.tierlist.json`, в редакторе «Импорт из файла» (та же схема).
2. **OSS репо `tiermaker/tiermaker-mcp`** (TypeScript, `@modelcontextprotocol/sdk`, stdio, `npx tiermaker-mcp`, MIT)
   - Состояние досок — в памяти процесса + опционально файл в рабочей папке.
   - Инструменты:
     - `search_templates(query, category?)`, `get_template(slug)` — публичные GET каталога (без авторизации, уже есть).
     - `create_tierlist(title, tiers?, template_slug?)` — с нуля (дефолт S/A/B/C/D) или из шаблона (его элементы в пул).
     - `set_tiers(board, tiers[])` — имена, цвета, порядок, добавить/удалить; `update_tier(board, tier_id, …)`.
     - `add_items(board, items[{label, image_url?}])`, `update_item`, `remove_items`.
     - `place_items(board, {tier_id: [item_ids]})`, `move_item(board, item, tier, position)`.
     - `get_tierlist(board)` — текущая структура (JSON) для самопроверки агентом.
     - `render_image(board, path?)` — PNG локально (satori/resvg или canvas), картинки качает MCP с таймаутом/лимитом.
     - `get_editor_link(board)` — ссылка `/create#tm=…` (или файл, если длинно).
   - Валидация и понятные ошибки (лимиты те же, что на сайте); User-Agent `tiermaker-mcp/<версия>`.
   - Тесты (vitest), CI на GitHub Actions, публикация в npm, README с примерами, заявки в реестр MCP / Smithery / awesome-mcp.
3. **Скилл** `skills/tiermaker/SKILL.md` в том же репо: как из запроса выбрать тиры, набрать 10–40 элементов, найти шаблон,
   проверить через `get_tierlist`, отдать PNG + ссылку; правила для картинок (прямые URL, без водяных знаков/чужих логотипов по возможности).
