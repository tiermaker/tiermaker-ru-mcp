## Что сделать
1. **SKILL.md** (остаться ≤ 120 строк):
   - отвечать на языке запроса пользователя (не языке темы/шаблона);
   - при просьбе > 200 элементов не дробить на несколько досок — сделать одну ≤ 200 и предложить сократить/разбить по критерию;
   - перед расстановкой проверить, нет ли очевидных и свежих пропусков по теме;
   - в ответе одной строкой назвать критерий расстановки;
   - одна ссылка в ответе;
   - картинки: сначала `search_images`, URL не выдумывать.
2. **`search_images(query, limit?)`** через Wikimedia Commons API (публичный, без ключа): возвращает прямые URL файлов (thumb ≤ 512px), подпись, лицензию и автора. Только `image/*` (jpeg/png/webp, не svg-скрипты), таймаут 8 с, User-Agent как у остальных запросов, limit ≤ 10. Ошибки сети → понятная ошибка, не падение. Тесты с моком сети. README: инструмент + строка о лицензиях Commons (атрибуция на пользователе).
3. **render_image**: перенос длинных подписей текстовых элементов (до 2–3 строк, дальше многоточие), без вылезания за плитку. Тест + 1 PNG-пример в отчёт.
4. **Эвалы**: проверка «ссылок в ответе ≤ 1»; кейсы с картинками ожидают `search_images` и проверку URL (как сейчас — 200 и `image/*`).
5. Два полных прогона эвалов, сравнение с baseline в отчёте: pass-rate, оценки судьи, стоимость, медиана вызовов/времени. Если что-то ухудшилось — описать причину.
