# T-065: Подготовка публичного исходного дерева tiermaker-mcp

## Цель
Подготовить безопасный к публикации исходный код под GitHub owner `tiermaker` (уточнение пользователя 2026-11-10).

## Контекст
- `../tiermaker-mcp/docs/publication-status.md`
- `.team/tasks/T-063-mcp-publication-readiness.report.md` и `.review.md`
- Пользователь подтвердил, что GitHub-профиль `tiermaker` нужен вместо <personal-gh-account>.

## Что сделать
- Подготовить изолированную публичную копию актуального исходного дерева без переписывания и разрушения исходной истории: чистый snapshot в отдельной директории / репозитории.
- Исключить внутренние сведения и непубличные email из публичного снимка и метаданных; сохранить публично полезную документацию и сведения о лицензиях и авторах. Достоверно указать владельца `tiermaker` в актуальных ссылках и метаданных.
- Сверить лицензии, историю публичного снимка, состав tgz и plugin zip, пересобрать артефакты и выполнить необходимые проверки в dev-контейнере. Указать исходный SHA снимка и отличия от проверенного приложения.
- Обновить changelog и документацию по правилам проекта; коммит в публичной копии с безопасными метаданными.
- Отчёт с точными путями, командами проверки и оставшимися рисками.

## Не делать
- Не менять оригинальную историю и не удалять данные. Не включать в публичную копию приватные артефакты, токены, сведения инфраструктуры или непубличные email.
- Не публиковать, не отправлять push, не создавать GitHub Release, не менять production или аккаунты в этой задаче.

## Приёмка
- Снимок содержит актуальный работающий MCP и документацию, не содержит упомянутых выше частных данных ни в истории, ни в архивах.
- Инструкции и ссылки указывают на реальный целевой owner; версия и changelog согласованы.
- Проверки и ограничения отражены в отчёте.

## Проверки
- Скан секретов и приватной информации по всей новой истории и составу архивов; focused и релевантные проверки пакета в dev-контейнере.
- Прод: только read-only, запись и публикация запрещены на этом этапе.
